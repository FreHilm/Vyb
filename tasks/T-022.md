## Goal

Let the user fix up the most recent commit without leaving the panel. Two
related actions:

- **Amend last commit** — fold whatever is currently staged into the
  previous commit (`git commit --amend`), preserving the existing message
  unless the user edits it.
- **Reword commit** — open a small dialog to rewrite the message of the
  most recent commit (or any commit reachable from HEAD that hasn't been
  pushed, if we want to extend it later).

## Acceptance Criteria

- [ ] "Amend" button visible in the commit area when there is no
  unstaged-only state and HEAD has at least one commit.
- [ ] Confirm dialog before amending if the commit has already been
  pushed to its upstream.
- [ ] Reword action available in the commit graph's right-click menu on
  HEAD; opens a dialog pre-filled with the existing subject + body.
- [ ] All three Git tabs refresh after either action.
