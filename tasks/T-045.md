## Goal

`Shift+Alt+F` (and a tab-bar / right-click action) reformats the
active editor buffer through Prettier. Picks up the project's
local Prettier config when one exists, falls back to sensible
defaults otherwise. Saves the round-trip to the shell or a
separate editor when the user just wants their JSON/TS prettified.

## Acceptance Criteria

- [x] `Shift+Alt+F` formats the active file in place via a
      CodeMirror keymap entry. Cursor preserved by line+column snap
      after the doc replacement.
- [x] Toolbar button next to Save / Save As / Reveal / Blame.
- [x] Honours `prettier.config.*` / `.prettierrc` /
      `package.json#prettier` via Prettier's own `resolveConfig`.
- [x] Supports JS/TS/TSX/JSON/CSS/HTML/Markdown — Prettier's
      parser inference from `filepath`. Python falls through to
      Prettier which then errors with an obvious "no parser" toast.
- [x] Failed format surfaces in a transient toast (auto-dismisses
      after 5s); the buffer is not touched.
- [x] Settings → Functions → "Format on save" toggle, default
      off. When on, Cmd+S runs the formatter first.

## Notes

- Prettier as an npm dependency is heavy (~5MB). Two options:
  (a) bundle Prettier with the app and run in the main process
  (simplest, single source of truth, but inflates the dmg),
  (b) shell out to `npx prettier` (smaller bundle, slower first
  invocation, requires node in the user's PATH).
  Recommend (a) — Prettier's stdin/stdout API is cheap to invoke
  and the user experience is identical across machines.
- Add Prettier to vite.main.config.ts externals so it isn't bundled
  into the renderer.
- Use `prettier.format(source, { filepath, ...resolvedConfig })` —
  the `filepath` arg lets Prettier infer the parser automatically.
- Cursor preservation: compute the cursor's offset in lines/columns
  before format, snap to the same line+column after. Don't try to
  do a precise text-position match — Prettier rewrites; an
  approximate restore is good enough.

## Progress

- 2026-05-14: Shipped. Added Prettier 3.8.3 as a runtime
  dependency, externalized in vite.main.config.ts so it stays out
  of any renderer bundle. New `file:format` IPC lazy-imports
  Prettier in main, runs `resolveConfig` against the file's path
  (so a repo's own `.prettierrc` etc. is picked up), then
  `format(content, { filepath, ...resolved })`. Inference of the
  parser from filepath gives free JS/TS/TSX/JSON/CSS/HTML/MD
  support.
  
  Renderer side: `handleFormat` reads the editor buffer, sends to
  IPC, replaces the doc with the result, snaps cursor to the same
  line/column. Errors surface in a transient toast. Wired via
  Shift+Alt+F (CodeMirror keymap) and a Format toolbar button.
  `formatOnSave` setting in Settings → Functions runs Prettier
  ahead of every save when enabled.
