## Goal

Vyb already supports `DEFAULT_AGENTS` + customisations. The next
step is **prompts**, not just agents: a saved library of common
kickoffs ("review the diff and report regressions", "explain this
file", "rebase onto main and resolve conflicts", "find and fix the
failing test"). Right-click in the agent terminal → pick a
playbook → it's typed in. Or bind to a number key. The Kanban
hook already shows this pattern works.
