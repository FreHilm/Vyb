## Goal

Add core git operations: stage/unstage files, commit, push, merge, list branches, switch branch, stash.

I want a tight integration of these operations, taking inspiration from the Fork application.

- The UI should make it obvious what is staged vs unstaged, and committing + pushing should be one or two clicks.
- A good branch tree with point-and-click checkout, again Fork-inspired.
- If a checkout would conflict with uncommitted changes, the user should be guided to resolve it (commit, stash, or discard) before the switch — never lose work silently.
- Easy stash management: list, apply, drop. Fork is the reference here too.

## Acceptance Criteria

- [ ] Stage/Unstage Files
- [ ] Commit
- [ ] Push
- [ ] List Branches - UI 
- [ ] Change branch
