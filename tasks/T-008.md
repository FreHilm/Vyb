## Goal
URLs displayed in the agent window should be clickable and open in the default browser.

## Acceptance Criteria

- [x] URLs (http/https) rendered in the agent terminal are visually identifiable on hover and clickable.
- [x] Plain left-click on a URL opens it in the OS default browser via `shell.openExternal`.
- [x] Behavior is limited to agent terminals (TerminalPane); shell terminals are unchanged.

## Notes
Scope confirmed with user: agent terminals only, plain-click activation.
Implementation: `@xterm/addon-web-links` wired into TerminalPane, with handler routed through existing `window.api.openUrl()` IPC.

## Progress

- 2026-04-26: Confirmed scope with user — agent terminals only, plain-click activation.
- 2026-04-26: Added `@xterm/addon-web-links@^0.12.0` (MIT) and updated `THIRD_PARTY_NOTICES.md`.
- 2026-04-26: Wired `WebLinksAddon` into `openTerminal()` in `src/renderer/components/TerminalPane.tsx` with a custom activate handler that routes the URI through the existing `window.api.openUrl` IPC (`shell.openExternal`) instead of the default `window.open`. The addon attaches only to agent-kind instances since `openTerminal` is the agent terminal lifecycle hook; `ShellPane` is unchanged.
