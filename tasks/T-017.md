## Goal

The hotkey labels sometimes get stuck showing. I would like them to auto-hide after 15 seconds.

## Acceptance Criteria

## Notes

## Progress

- Cause: `useKeyNav` flips `navActive` to `true` on modifier keydown and back to `false` on keyup or window blur. If neither event reaches the renderer (focus stolen by another window/system dialog while the modifier is still held, OS swallowing the release), the overlay stays on indefinitely.
- Fix in `src/renderer/components/KeyNav.tsx`: added a small effect that schedules a 15s `setTimeout` whenever `navActive` becomes true. Normal release clears the timer via the effect's cleanup; the timer only fires (and forces `navActive` to false) if the release was missed.
