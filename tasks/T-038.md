## Goal

Show a small avatar (gravatar by default) next to each commit row in
the Tree tab so a long graph scans visually by author rather than by
reading text.

## Acceptance Criteria

- [ ] Each commit row gets a 16-20 px avatar in the author column.
- [ ] Avatars resolved from the gravatar URL using the lowercase MD5 of
      the trimmed email; cached in-memory + on-disk so we don't fetch
      per row scroll.
- [ ] Falls back to a generated colour-from-email circle with the
      author's initials when offline / 404.
- [ ] Toggleable in Settings → Functions ("Show author avatars",
      default on).

## Notes

Gravatar fetch should be best-effort with a tight timeout (e.g. 3 s)
so the graph never blocks rendering on network.
