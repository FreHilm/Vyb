## Goal

Add a safe force-push option (`git push --force-with-lease`) for branches
whose history has diverged from the upstream — e.g. after an amend or a
rebase. The default push should stay non-force; force-with-lease is an
explicit second action so a misclick can't rewrite someone else's work.

## Acceptance Criteria

- [ ] In the panel status bar's Push button: a small dropdown chevron or
      a long-press / right-click reveals "Force-push (with lease)".
- [ ] Force option is only enabled when the local branch has diverged
      (ahead > 0 AND behind > 0 OR the working-tree branch points at a
      different SHA than the upstream tracks).
- [ ] Confirm dialog before firing the force-push, listing the upstream
      and the local SHA that will replace it.
- [ ] Surface any rejection message in the existing error banner.

## Notes

Important pairing with Amend (T-022) and Interactive rebase (T-033) —
those rewrite history and are unusable without this.
