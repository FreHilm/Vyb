## Goal

Today Pull is plain `git pull` (fast-forward / merge). Many teams
prefer rebasing local commits on top of the remote tip to keep history
linear. Surface this as both a per-action choice and a per-profile
default.

## Acceptance Criteria

- [ ] Pull button has a dropdown chevron: "Pull (merge)" / "Pull
      (rebase)".
- [ ] Settings → Functions exposes a default for the active profile:
      Merge / Rebase / Ask.
- [ ] On rebase mode, behave like Pull — only enabled when behind > 0,
      and surface conflicts via the in-progress banner (depends on
      T-025 for the resolution UI).

## Notes

`git pull --rebase=true` under the hood. Re-uses the existing rebase
abort/continue plumbing already in place.
