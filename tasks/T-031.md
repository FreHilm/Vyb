## Goal

Make large commit graphs navigable. A persistent search box at the top
of the Tree tab filters commits by message, author, SHA prefix, or
touching-file path; matched commits highlight in the graph and
non-matches dim.

## Acceptance Criteria

- [ ] Search input above the graph. Updates as the user types
      (debounced 150 ms).
- [ ] Matches on commit subject, author name/email, SHA prefix, and
      "touches file" path-spec.
- [ ] Matched commits keep their normal colour; non-matches dim to
      ~30% opacity but stay positioned to preserve the graph topology.
- [ ] `Enter` jumps to the next match; `Shift+Enter` to the previous;
      Esc clears.

## Notes

Initial implementation can search the already-loaded commit window
client-side. For very large repos, add a "load more" or server-side
filter via `git log --grep=… --author=… -- <path>`.
