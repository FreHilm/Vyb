## Goal

For users who sign their commits, surface signature status in the
commit graph and let the user toggle signing on / off per profile.

## Acceptance Criteria

- [ ] Each row in the Tree tab gets a small signature indicator:
      verified (green), bad (red), unsigned (no icon). Tooltip shows
      the key id / signer name.
- [ ] Settings → Functions has a "Sign commits" toggle per profile
      (writes `commit.gpgsign true` to the repo's local config).
- [ ] When signing is on but the GPG agent isn't available, surface a
      clear error in the commit error banner rather than a silent
      failure.

## Notes

`git log --show-signature` for verification status (parse the
`gpg: …` lines). For the toggle, write to `.git/config` directly via
`git config --local commit.gpgsign true|false`.
