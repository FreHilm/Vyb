## Goal
Improve color contrast for added/removed/modified change indicators.
Make the disclosure arrow icon larger — it is too small.

## Acceptance Criteria

- [x] Diff line backgrounds (`+`/`−`) are clearly visible — no longer washed out
- [x] Status badges (M/A/D/U/R) have readable contrast against their pill background
- [x] `+N` / `−N` count chips read clearly
- [x] Disclosure arrow on file rows is visibly larger

## Notes

User screenshot showed the diff `+`/`−` line tints at opacity 0.1 are nearly invisible against the dark base, and the text on those lines is the same pastel green/red as the tint, so nothing reads. Status badge `M` was also low contrast (subtext0 on surface2).

All tints use `color-mix(in srgb, var(--c-X) Y%, transparent/mantle)` so they follow the live theme's hue rotation instead of being hardcoded to default-theme HSL values.
