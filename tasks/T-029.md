## Goal

Add a side-by-side rendering mode for diffs (old version on the left,
new on the right, synchronised scrolling). Many users find it easier
to read than the current unified view, especially for larger changes.

## Acceptance Criteria

- [ ] A toggle (button or per-file menu) flips a diff between unified
      and side-by-side.
- [ ] Side-by-side aligns lines by hunk: removed lines on the left,
      added lines on the right, unchanged lines paired across both.
- [ ] Scroll, line numbers, and horizontal scrollbars stay in sync
      between the two panes.
- [ ] Setting is per-panel — applies to the Changes tab, file history
      diffs (T-026), and compare results (T-028).

## Notes

Easiest path is to parse the existing unified diff text into a structured
hunk model and render two columns from it.
