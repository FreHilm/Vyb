## Goal

Be Able to run multiple agents on the same project, using GitFlow and different branches. 
This should be a per Agent profile setting. If enabled a new agent thread should spawn. This should be done when implementing using the kanban board (This should not be default using the regular agent). So choosing a task from kanban spawns the new agent terminal with the task, (There should also be an auto mode, where the enter is triggered directly so the agent works directly or non auto, user can manually edit before triggering the agent). In the agent profile panel a new row under the agent, specifying the task name and title. When done the agent should be still visible but if the user leaves it after inspection it should automatically be removed. If stopped it should be removed. Also important, spawn and copy the content of the repo to a temp area, so the agent has its own local copy. Git - should create a new feature brach, commit and push the feature branch and create a pull request.
