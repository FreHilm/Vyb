## Goal

A diff view that takes two refs (branch / tag / commit) and shows the
full set of changed files between them, with per-file diffs. Used for
code review, "what's about to land in this PR", and verifying merges.

## Acceptance Criteria

- [x] Branches tab right-click → "Compare with…" → picker for the other
      ref. Same action available from the Tree tab on a commit.
- [x] Result view shows a file list (with +/− counts) and per-file
      diffs, reusing the Changes tab's diff renderer.
- [x] Direction toggle (a..b vs b..a) — the UI defaults to "what would
      arrive in target if we merged source".
- [x] Optional checkbox: "Show only files in the merge base..tip range"
      vs "all differences".

## Notes

`git diff <a>...<b>` for merge-base range, `git diff <a>..<b>` for
straight range. `--name-status` for the list, then per-file diff on
demand. Same plumbing the Changes tab already uses.

## Progress

- 2026-05-14: Shipped. New Compare tab (visible only when a compare is
  active, with an × to close). Opened from Branches / Tree tabs via the
  "Compare with …" context-menu item. Two-pane layout: file list (+/−,
  status badge) on the left, full diff on the right reusing the
  word-level highlighting from T-030. Direction swap button + three-dot
  toggle ("merge-base range" vs "every difference"). Backed by two new
  IPC handlers: `git:compareFiles` (numstat + name-status -z, rename
  aware) and `git:compareFileDiff` (per-file diff body).
