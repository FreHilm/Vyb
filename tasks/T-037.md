## Goal

Today Push only sends the branch's commits. Let the user opt to also
push tags — either every tag (`--tags`) or just the tag(s) reachable
from the pushed branch (`--follow-tags`).

## Acceptance Criteria

- [ ] Push button's dropdown (introduced in T-024) gains "Push with
      tags" and "Push reachable tags".
- [ ] Settings → Functions has a default for which behaviour Plain
      Push uses: Off / Reachable / All.
- [ ] Tag-related errors (e.g. tag already exists upstream) surface in
      the panel error banner with the offending tag name.

## Notes

`git push --tags`, `git push --follow-tags`. Should respect upstream
config; refuse to overwrite remote tags without explicit consent (no
silent force on tags).
