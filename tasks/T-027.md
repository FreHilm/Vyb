## Goal

Per-line authorship for any open file: who last touched each line and
in which commit, with the option to jump from a blamed line to the
commit's full diff. Pairs naturally with file history (T-026).

## Acceptance Criteria

- [ ] Right-click in the editor → "Blame this file" toggles a gutter
      that shows commit short-SHA + author + relative date per line.
- [ ] Clicking a blame entry opens the commit in the Tree tab (or in
      the file-history panel from T-026, if open).
- [ ] Blame stays in sync as the user scrolls — gutter rows align with
      editor rows.
- [ ] Toggle persists per file path so re-opening remembers the choice.

## Notes

`git blame --line-porcelain <file>` gives one record per line with
author, time, commit, summary. Parse once on toggle, cache by file
path until the buffer changes.
