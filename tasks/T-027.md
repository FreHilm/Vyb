## Goal

Per-line authorship for any open file: who last touched each line and
in which commit, with the option to jump from a blamed line to the
commit's full diff. Pairs naturally with file history (T-026).

## Acceptance Criteria

- [x] A "Blame" toggle in the file tab's toolbar shows a gutter with
      commit short-SHA + author initials + relative date per line.
      (Toolbar button rather than editor right-click — CodeMirror's
      built-in context menu makes a dedicated right-click action
      finicky to wire and the toolbar discovery is at least as good.)
- [x] Clicking a blame entry opens the commit in the file-history
      overlay from T-026, preselected to the clicked SHA.
- [x] Blame stays in sync as the user scrolls — it's a real
      CodeMirror gutter, so it aligns natively with editor rows.
- [ ] Toggle persists per file path so re-opening remembers the
      choice. *(V2 — currently per-session, lost on profile switch /
      app restart)*

## Notes

`git blame --line-porcelain <file>` gives one record per line with
author, time, commit, summary. Parse once on toggle, cache by file
path until the buffer changes.

## Progress

- 2026-05-14: Shipped. New `git:blameFile` IPC parses
  `git blame --line-porcelain`, caching author/time/summary per SHA so
  the parser stays O(n). The renderer-side `blame-gutter.ts` builds a
  CodeMirror gutter that renders short-SHA + author initials +
  relative date per line; adjacent identical SHAs hide the SHA pill
  to keep stretches calm. Clicking a marker opens the T-026 file
  history overlay with that commit preselected. Toggled per active
  tab via a new "Blame" button in the file toolbar; remounts the
  editor through the existing mountEditor path. Persistence and a
  real editor right-click menu are V2.
