## Goal

Show the full history of commits that touched a specific file: a
filterable commit list plus the diff of that file for the selected
commit. Useful for tracing when a regression landed or why a line was
written the way it is.

## Acceptance Criteria

- [x] Right-click in the file tree → "Show history" opens a new
      panel (overlay or split inside the Files tab) listing commits
      that touched the file, newest first.
- [x] Selecting a commit shows the diff of that file at that commit.
- [x] Renames are followed (use `git log --follow`).
- [ ] Pagination or virtualisation for long histories so a 10k-commit
      file doesn't choke the UI. *(V2 — current cap is 5000 commits)*

## Notes

Underlying command:
`git log --follow --format=<porcelain> -p -- <file>`
We already parse `git log` for the Tree tab; reuse that pipeline with
the `--follow` and path-spec extension.

## Progress

- 2026-05-14: Shipped. New `FileHistoryView` overlay opened from the
  File Explorer's right-click menu → "Show history". Two-pane layout:
  commit list (subject + short SHA + author + relative date, filtered
  by free-text search and navigable with ↑/↓ or j/k) on the left, full
  per-commit diff of just this file on the right via the now-exported
  `FileDiff` component. Backed by two new IPCs: `git:fileLog` (uses
  `git log --follow` so renames are chased) and `git:fileLogDiff`
  (diffs against the commit's first parent, or the empty tree for root
  commits so additions render). Capped at 5000 commits without
  virtualisation — virtualisation deferred to V2.
