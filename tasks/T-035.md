## Goal

Vyb already spawns worktrees for parallel agents, but there's no
general UI for the worktrees a user might create themselves. List
them, switch between them, and remove them — without leaving the panel.

## Acceptance Criteria

- [x] New "Worktrees" section in the Branches tab (default open).
- [x] Each row shows path, the branch it points at, and badges for
      main / locked / current / system-managed.
- [x] Right-click: Show in Finder, Open in VS Code, Remove. Remove
      retries with --force when git refuses for dirty/locked state,
      surfacing git's own reason in the confirmation. "Open in shell
      inside Vyb" is V2 — needs ShellPane plumbing.
- [x] An "Add worktree" "+" action reuses `GIT_ADD_WORKTREE` with a
      small dialog (path + branch, datalist-populated with locals).

## Notes

`git worktree list --porcelain` gives the canonical list. Be careful
about the parallel-agent worktrees living under Vyb's app-support
directory — filter them out of this UI (or mark them clearly) so
users don't accidentally remove an agent's workspace.

## Progress

- 2026-05-14: Shipped. Two new IPCs — `git:listWorktrees` parses
  `git worktree list --porcelain` into `{path, branch, head, isMain,
  isDetached, isBare, isLocked, lockedReason, isSystemManaged}`; the
  `isSystemManaged` flag is set when the path lives under
  `app.getPath('userData')/parallel-agents/` so the renderer can
  protect those rows. `git:removeWorktree` refuses to touch the main
  worktree (cross-checked via `git rev-parse --git-common-dir`) or
  any system-managed path as a belt-and-suspenders guard.
  
  Branches-tab Worktrees section opens by default; user-managed
  worktrees come first, then a "Managed by Vyb" sub-header before
  system-managed rows (rendered dimmed with Remove disabled +
  tooltip explanation). Right-click menu offers Show in Finder,
  Open in VS Code, and Remove. Remove first tries without `--force`;
  on dirty/locked refusal it re-prompts with a Force checkbox and
  git's own reason text. Add reuses the existing GIT_ADD_WORKTREE
  IPC; the dialog autocompletes the branch field from the local
  branch list.
