## Goal

`Cmd+Shift+F` opens a global search panel that finds a term across
every file in the active profile's working directory. Results
group by file, click-through opens the matching file pre-scrolled
to the line. Essential once a repo is more than a handful of files
— in-file find (Cmd+F) gets you nowhere when you don't know which
file the symbol lives in.

## Acceptance Criteria

- [x] `Cmd+Shift+F` opens a floating Find-in-Files panel anchored
      to the top-right.
- [x] Toggles for case-sensitive (Aa), whole-word (ab), regex (.*).
- [x] Include / exclude glob fields. Globs accepted comma- or
      newline-separated.
- [x] Each result row: file path (relative), line number, line
      content with the matched substring highlighted.
- [x] Click → opens the file at the matched line via the existing
      `pendingFileOpen` route.
- [x] Respects `.gitignore` because ripgrep does by default. No-git
      directories use ripgrep's standard ignore rules.
- [x] Cancellable: typing a new query bumps a `requestId` ref and
      drops the previous request's result when it eventually
      arrives.
- [ ] Streaming results during the scan. *(V2 — current
      implementation batches up to 500 matches per query with a
      30s timeout; ripgrep returns under a second on typical
      repos so single-shot is fine for now.)*

## Notes

- Use ripgrep (`rg`) via the main process — `rg --json` is the
  easiest streamable output, one JSON object per match. Avoid
  spawning a fresh process per keystroke; debounce the input ~150ms.
- If `rg` isn't on PATH, fall back to a node-glob + per-file regex
  scan and show a "ripgrep not installed — install for faster
  search" hint. Keep this fallback minimal.
- `mountEditor(filePath, gotoLine)` in FileExplorer.tsx already
  accepts a 1-based line number and scrolls it into view — that's
  the click-through path.
- The overlay can mount inside the Files tab on the left side,
  pushing the tree narrower while it's open. Match the existing
  resizable-pane idiom (ResizeHandle).

## Progress

- 2026-05-14: Shipped. New `file:searchInFiles` IPC spawns
  `rg --json` with arguments derived from the user's toggles
  (`-i` unless case-sensitive, `-w` for whole word, `-F` for
  fixed-string when regex is off). Include/exclude globs map to
  ripgrep's `-g pat` / `-g !pat`. Parses the newline-delimited
  JSON stream, caps at 500 matches, 30s timeout, kills the
  ripgrep process if either cap is hit. When ripgrep isn't on
  PATH the IPC returns `fallbackUsed: true` so the panel can show
  an "install ripgrep" hint.
  
  New `FindInFilesPanel` renderer component opens as a floating
  overlay. Debounces queries 200ms, drops stale results via a
  `requestId` ref, groups matches by file with per-group collapse,
  highlights the matched substring inline. Cmd+Shift+F toggles
  open/closed via the existing global keydown handler.
  
  Streaming (so partial results appear during long scans) is V2 —
  for the repos most users hit, ripgrep returns in well under a
  second, so batch-fetch is fine.
