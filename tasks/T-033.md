## Goal

Drag-and-drop interactive rebase for a range of commits on top of HEAD
(or onto any other commit). Per-commit actions: pick, reword, squash,
fixup, edit, drop. Driven by a Vyb-owned editor that replaces the
default `GIT_SEQUENCE_EDITOR`.

## Acceptance Criteria

- [ ] Tree tab right-click on a commit → "Rebase commits since this…"
      opens a list of the commits between that one and HEAD.
- [ ] User can drag rows to reorder, and pick an action per row.
- [ ] On submit, Vyb writes the corresponding todo list and runs
      `git rebase -i --onto=… …` with the env-var override for the
      sequence editor so the prepared list is consumed without an
      external editor.
- [ ] Conflicts and stop-for-edit pauses surface in the existing
      rebase banner with Continue / Abort buttons.

## Notes

Implementation pattern: set `GIT_SEQUENCE_EDITOR` to a tiny helper
binary (or `sh -c "cat <vyb-tmp-todo> > "$1""`) that writes our
prepared list and exits 0. Similarly `GIT_EDITOR` for reword stops.
