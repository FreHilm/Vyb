## Goal

Vyb spawns expensive agents and currently shows almost nothing
about what they cost or what they're doing internally. A small
panel showing:

- Tokens used per agent this session
- Time spent in `working` vs `needs-input` vs `idle`
- Approximate $ cost
- A history strip of "what each agent did" (tasks completed,
  files touched)

This leans *into* the multi-agent identity. Nobody else has this
view because nobody else has Vyb's parallel-agent infrastructure.
