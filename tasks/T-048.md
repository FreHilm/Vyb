## Goal

Vyb has accumulated a lot of actions — git operations, file ops,
agent controls, settings, view toggles. Most of them are reachable
only by clicking through menus or remembering specific shortcuts.

A single fuzzy-searchable palette ("Format Document", "Push
branch", "Toggle agent", "Reveal in tree", "Switch to profile X")
would expose everything and make the keyboard the primary
interface. This is the single change that would most change how
Vyb *feels* to use day-to-day.
