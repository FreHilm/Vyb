## Goal

A simple browser for `git reflog`. Recovery tool — when a user
accidentally amends / resets / branch-deletes and wants to find the
previous state, they shouldn't have to drop to the terminal.

## Acceptance Criteria

- [ ] Tree tab gets a "Reflog" toggle (or a dedicated sub-tab) that
      shows the reflog as a list: short-SHA, ref label, action,
      relative time, subject.
- [ ] Right-click → "Checkout this state" (creates a new branch
      pointing at the entry's SHA, optionally), "Reset current branch
      to here", "Copy SHA".
- [ ] Reset action goes through the existing
      confirm-with-options reset flow (soft / mixed / hard).

## Notes

`git reflog --format=<porcelain>` for the data. Be mindful the reflog
is per-ref; default to `HEAD`'s reflog, with a small picker for other
refs if we want to extend later.
