## Goal

Two related context-preserving editor bits VS Code calls
"Breadcrumbs" (path bar at the top of the editor) and "Sticky
scroll" (current scope's headers pinned at the top of the viewport
while scrolling).

Both make it easier to keep your bearings inside a large file:
breadcrumbs answer "where am I in the project + file?", sticky
scroll answers "which function/class is the visible code part of?".

## Acceptance Criteria

- [ ] **Breadcrumbs row** above the editor: shows the file's path
      from the working directory root, segments are clickable to
      reveal in the file tree.
- [ ] Last breadcrumb segment also shows the current symbol scope
      (function / class / heading) inferred from the cursor
      position when language support allows.
- [ ] **Sticky scroll**: when the viewport scrolls past a
      function/class/heading declaration, that line pins to the
      top of the editor pane. Nested scopes stack (max 3 deep).
      Click a sticky header to scroll the editor back to that
      declaration.
- [ ] Toggle in Settings → Editor (or via View menu): "Sticky
      scroll", "Breadcrumbs". Both default on.
- [ ] Plays nice with the existing blame gutter from T-027 (sticky
      header sits above gutter + content, doesn't shift blame
      alignment).

## Notes

- Scope detection: the cheap path is regex per language (top-level
  `function`/`class` for JS/TS, `def`/`class` for Python, `#` for
  markdown). The richer path uses CodeMirror's syntax tree —
  `syntaxTree(state).resolveInner(cursor.from)` and walk up looking
  for nodes named `FunctionDeclaration` / `ClassDeclaration` etc.
  Start with the tree-walk approach for JS/TS, fall back to regex
  for Python/CSS/HTML/Markdown where the CM language modes are
  thinner.
- Sticky scroll: CodeMirror doesn't ship a built-in. The standard
  pattern is an `EditorView` plugin that watches `viewportChanged`
  and renders an absolutely-positioned overlay above the scroller
  containing copies of the in-scope declaration lines. Style with
  a subtle bottom border + slightly elevated background.
- Breadcrumbs row needs ~24px of vertical space — adjust the tab
  bar / editor flex layout accordingly.
- The "click breadcrumb segment to reveal in tree" action reuses
  the same `revealRequest` path T-043 wires up for "reveal current
  file in tree".
