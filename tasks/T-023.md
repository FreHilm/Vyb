## Goal

Today staging is all-or-nothing per file. Add the ability to stage (or
unstage) individual hunks and individual lines from a file's diff, so a
user can break a noisy working copy into clean, focused commits without
juggling the index by hand.

## Acceptance Criteria

- [ ] Each hunk header in the diff view has a "Stage hunk" / "Unstage
      hunk" action.
- [ ] Selecting a line range inside a hunk exposes "Stage selection" /
      "Unstage selection".
- [ ] The action sends the matching hunk/lines through
      `git apply --cached` (or `--reverse --cached`) so the index ends
      up at exactly the chosen subset.
- [ ] After staging, the file shows up in both the staged and unstaged
      lists with the appropriate per-side diffs.
- [ ] Works for added, modified, and deleted files; gracefully refuses
      on binary files.

## Notes

Likely needs a new IPC + a small hunk-patch builder. Test cases should
cover CRLF normalisation and trailing-newline preservation.
