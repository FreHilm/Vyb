## Goal

Add, rename, change URL on, and remove remotes from inside the Git
panel — no need to drop to the terminal for a one-line config change.

## Acceptance Criteria

- [x] Branches tab gets a "Remotes" section header with a "+" to add a
      new remote (name + URL).
- [x] Right-click on a remote: Rename, Edit URL, Remove.
- [x] After every change, the Branches list reloads (refs may have
      moved). Status bar ahead/behind picks up via its own polling
      cycle; explicit panel-side bump deferred to V2 if needed.
- [x] Confirm before Remove if any local branch tracks the remote
      (count + first three names shown).

## Notes

Underlying commands: `git remote add`, `git remote rename`,
`git remote set-url`, `git remote remove`. Plus a `git remote -v` for
the listing.

## Progress

- 2026-05-14: Shipped. Six new IPCs handle the config CRUD:
  `git:listRemotes` (parses `git remote -v` into `{name, fetchUrl,
  pushUrl}` rows), `addRemote`, `renameRemote`, `setRemoteUrl` (`opts.push`
  for the V2 split-URL UI), `removeRemote`, and a small
  `remoteTrackingBranches` helper used to populate the
  remove-confirmation dialog. The Branches tab's Remotes section is
  now driven by the configured-remote list (not the ref tree), so
  remotes with no fetched branches still appear as empty folders.
  Section header has a "+ Add remote" button; right-click on a
  remote folder opens a Rename / Edit URL / Remove menu. URL field
  accepts anything git accepts (HTTPS, SSH, local paths).
