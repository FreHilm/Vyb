## Goal

Add, rename, change URL on, and remove remotes from inside the Git
panel — no need to drop to the terminal for a one-line config change.

## Acceptance Criteria

- [ ] Branches tab gets a "Remotes" section header with a "+" to add a
      new remote (name + URL).
- [ ] Right-click on a remote: Rename, Edit URL, Remove.
- [ ] After every change, the Branches list reloads (refs may have
      moved) and the panel status bar's branch + ahead/behind
      re-computes.
- [ ] Confirm before Remove if any local branch tracks the remote.

## Notes

Underlying commands: `git remote add`, `git remote rename`,
`git remote set-url`, `git remote remove`. Plus a `git remote -v` for
the listing.
