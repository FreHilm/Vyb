## Goal

Vyb is git-deep and agent-driven — the natural pairing is to bring
PRs in. Right-click a remote branch → "Show PR" → opens an inline
panel with the description, comments, file diffs with comment
threads. The agent can read those comments and address them. The
`gh` CLI provides everything; it just needs surfacing.

This closes the loop: write code with the agent → push → review
the PR inline → ask the agent to address review comments → merge —
all without leaving Vyb.
