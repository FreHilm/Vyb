## Goal

The flames should never detach from the base. Currently there is a visible gap between the base bar and the flame spikes during animation.

## Acceptance Criteria

- [ ]

## Notes

## Progress

- Identified cause: each `.flame` spike path animates `transform: scaleX(...)`. SVG `<path>` elements default to `transform-origin: 0 0` (viewBox origin), so when scaleX > 1 the spike's left edge (at x=3) is pushed rightward — creating a visible gap between the base bar (x=0–3) and the spike.
- Fix in `src/renderer/App.css`: added `transform-origin: 3px 0` to `.flame`, anchoring all per-spike scale animations to the right edge of the base bar. Spikes now grow/shrink horizontally without detaching.
