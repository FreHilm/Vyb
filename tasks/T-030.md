## Goal

Within a changed line, highlight the specific words / tokens that
differ instead of marking the whole line as added/removed. Massively
improves readability of small edits inside long lines.

## Acceptance Criteria

- [ ] Each pair of removed + added lines computes an intra-line diff
      and highlights the diff regions with a stronger background.
- [ ] Works in both unified and side-by-side rendering.
- [ ] Configurable granularity (word vs char) — start with word.
- [ ] No perceivable slowdown on a typical file (<10 ms per hunk).

## Notes

Either `git diff --word-diff=porcelain` and parse it, or compute in the
renderer with a small Myers / patience diff on the two strings. The
JS-side option keeps things synchronous and avoids round-tripping
through git for every visible hunk.
