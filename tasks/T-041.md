## Goal

Guided `git bisect` from the Git panel: start, mark current state
good/bad, step, reset. Great for hunting regressions in long
histories.

## Acceptance Criteria

- [ ] Tree tab right-click on a commit → "Start bisect from here as
      good" / "…as bad". A persistent bisect banner appears at the
      top of the panel.
- [ ] Banner buttons: "Mark current good", "Mark current bad",
      "Skip", "Reset".
- [ ] Each mark checks out the next bisect step and updates the
      banner with progress (steps remaining, narrowed range).
- [ ] On a found commit, banner shows the result and offers "Open in
      Tree" + "Reset bisect".

## Notes

`git bisect start <bad> <good>`, `git bisect good|bad|skip`,
`git bisect reset`, `git bisect log` for progress info. Conflicts
mid-bisect surface via the same in-progress banner machinery (T-025).
