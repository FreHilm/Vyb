## Progress

- Restyled CodeMirror's built-in search panel (Cmd+F) via `EditorView.theme({...})` in `src/renderer/components/FileExplorer.tsx`. Targets the panel container, text inputs, action buttons, checkbox labels, and the close (X) button.
- Colours pulled from the same Catppuccin CSS vars the rest of the app uses (`--c-mantle` / `--c-base` / `--c-surface1` / `--c-text` / `--c-subtext0` / `--c-overlay0`), so the panel auto-adapts to hue + darkness changes from Settings → Appearance.
- Search match highlights inside the editor now use `--c-yellow` at 25% / 50% via `color-mix`, giving a clear "match" / "selected match" distinction without harshness.
- Inputs use the same 6px radius and 26px height as command-bar action buttons; close button is positioned top-right with subtle hover.
